# Fotoğraflar

Sitedeki fotoğrafları kendi işlerinizin fotoğraflarıyla değiştirmek için,
aşağıdaki isimlerle bu klasöre `.jpg` dosyası koymanız yeterli. Dosya
varsa site onu gösterir; yoksa yedek stok görsel kullanılır.

| Dosya adı          | Nerede görünür                         | Önerilen oran |
|--------------------|----------------------------------------|---------------|
| `hero.jpg`         | En üstteki büyük fotoğraf              | dikey, 4:5    |
| `sarj.jpg`         | "Şarj istasyonu" bölümü                | yatay, 4:3    |
| `topraklama.jpg`   | "Topraklama ve pano" bölümü            | yatay, 4:3    |
| `galeri-1.jpg`     | "Sahadan" galerisi, büyük kare         | kareye yakın  |
| `galeri-2.jpg` … `galeri-5.jpg` | "Sahadan" galerisi        | yatay         |

İpucu: Telefonla çekilen fotoğrafları yüklemeden önce 1600 px genişliğe
küçültmek sitenin hızlı açılmasını sağlar.
